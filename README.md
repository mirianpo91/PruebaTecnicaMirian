# Prueba técnica - Panel de productos

### Objetivo
Revisar y mejorar el mini panel de productos identificando problemas, corrigiendo errores y aplicando buenas prácticas en todos los niveles del proyecto.

### Stack
- Vue 3 (Composition API)
- Pinia
- PrimeVue + PrimeFlex
- Vite
- Node.js (Express mock backend)

### Instrucciones

Esta prueba técnica está diseñada para evaluar tu capacidad de:
- **Identificar problemas** en diferentes capas del código (maquetación, lógica, arquitectura)
- **Detectar código duplicado** y oportunidades de refactorización
- **Aplicar buenas prácticas** de desarrollo frontend y backend
- **Mejorar la calidad** del código existente

### Tareas principales

1. **Revisión completa del proyecto**: Examina todos los archivos del proyecto y identifica qué mejorarías a todos los niveles:
   - Maquetación y estilos (SASS, arquitectura 7-1)
   - Lógica de componentes y composables
   - Gestión de estado (Pinia)
   - Servicios y manejo de errores
   - Backend y endpoints
   - Estructura de archivos y organización
   - Cualquier otro aspecto que consideres mejorable

2. **Corrección de problemas identificados**: Corrige los problemas que encuentres aplicando las mejores prácticas correspondientes.

3. **Refactorización**: Si identificas código duplicado, inconsistencias o oportunidades de mejora, refactoriza siguiendo buenas prácticas.

4. **Entrega**: Crea una **Merge Request** con:
   - Un mensaje claro describiendo los cambios realizados
   - Explicación de los problemas encontrados y cómo los resolviste
   - Justificación de las mejoras implementadas

### Duración recomendada
1 a 2 horas máximo.

### Notas importantes

- **Cualquier archivo del proyecto es susceptible de ser mejorado**. No te limites solo a los problemas obvios.
- Se valorará especialmente la capacidad de detectar problemas sutiles y proponer soluciones elegantes.
- La calidad del código y la atención al detalle son más importantes que la cantidad de cambios.
- Si identificas mejoras que no puedes implementar en el tiempo disponible, menciónalas en la descripción de la MR.

### Bonus (opcional)
- Añade un loader o un toast.
- Implementa eliminación de productos.
- Mejora la organización del store o los estilos.
- Cualquier otra mejora que consideres valiosa.
